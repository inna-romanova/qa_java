Проект qa_java: Автоматизация тестирования приложения 

Проект посвящен рефакторингу архитектуры и модульному тестированию классов, моделирующих поведение кошачьих (`Cat`, `Feline`, `Lion`), с использованием стека технологий автоматизации на Java.

 Выполненный рефакторинг и архитектурные решения

1. Разделение зависимостей (Dependency Injection):
   Из класса `Lion` удалено жесткое создание объекта `new Feline()`.
   Реализовано внедрение зависимости через конструктор: `public Lion(String sex, Feline feline)`. Теперь класс `Lion` изолирован и не управляет жизненным циклом `Feline`.
2. Изоляция компонентов с помощью Mockito:
   При тестировании классов `Cat` и `Lion` применены мок-объекты (`@Mock`) для подмены поведения класса `Feline`.
   Инициализация моков настроена через аннотацию `@Before` при помощи метода `MockitoAnnotations.openMocks(this)`, что обеспечивает независимость тестов.
3. Параметризация тестов (JUnit 4):
   Выделен отдельный тестовый класс `LionParameterizedTest` для проверки влияния пола льва (`Самец` / `Самка`) на наличие гривы (`hasMane`).
   Создан отдельный класс `FelineKittensParameterizedTest` для проверки корректности возвращаемого количества котят при передаче различных числовых значений.
4. Тестирование исключений:
   Внедрена классическая для JUnit 4 проверка генерации исключений через конструкцию `try-catch` и вызов `fail()` для покрытия блока `else` в конструкторе `Lion`.
